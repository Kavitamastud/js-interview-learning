🚀 JavaScript Hoisting - Complete Guide

What is Hoisting?
Hoisting is a JavaScript mechanism where variable and function declarations are moved to the top of their scope (global or function scope) during the compilation phase, BEFORE the code is executed.

Important: Only DECLARATIONS are hoisted, NOT INITIALIZATIONS!

📋 Check the Console (F12) to see all examples in action!

Note: Some examples in the console may show errors intentionally to demonstrate the Temporal Dead Zone (TDZ) concept with let/const.
