🔑 Key Concepts

setTimeout:
Executes a function after a specified delay. It's asynchronous - it doesn't block code execution.
Closure:
A function has access to variables in its outer (enclosing) scope even after the outer function has returned.

🎯 The Classic Problem

for (var i = 0; i < 3; i++) {
    setTimeout(function() {
        console.log(i); // Prints: 3, 3, 3 ❌
    }, 1000);
}
Why? var is function-scoped. By the time setTimeout callbacks run, the loop has finished and all callbacks see the same 'i' value (3).

✅ Solutions

Solution 1: Use let (Recommended)
let is block-scoped, so each iteration creates a new variable.
Solution 2: IIFE (Immediately Invoked Function Expression)
Creates a new scope for each iteration.
Solution 3: setTimeout Third Parameter
Pass values directly to the callback function.
